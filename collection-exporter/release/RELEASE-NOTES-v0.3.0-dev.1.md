# Collection Exporter 0.3.0-dev.1

Development tester build.

## Highlights

- Clean two-column screen with live category counts.
- Unique selected total and named unresolved records.
- Local-time Cobblemon Town report header.
- Mythical and Legendary report subgroups.
- Legendary/Mythical labels inside Custom Skins.
- No redundant Shiny suffix in the Shiny section.
- Compact summary with zero-value diagnostics omitted.
- Classification source and aspect research retained in the development workbench, not
  shipped as user-facing documentation.

## Compatibility

- Minecraft 1.21.1
- Fabric Loader 0.18.0 or newer
- Fabric API 0.116.7+1.21.1 or newer
- Cobblemon 1.8.2
- Java 21 or newer
- Client-only

## Validation

- Built from the public source with a clean Gradle test/build.
- Not a claim of exhaustive in-game compatibility across every GUI scale or server state.
- Unknown and unresolved aspects remain visible rather than being silently suppressed.
