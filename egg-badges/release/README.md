# Egg Badges 0.2.4

Install `egg-badges-0.2.4.jar` in a Fabric 1.21.1 client's `mods` folder. The mod
requires Fabric Loader `>=0.18.0`, Fabric API `>=0.116.7+1.21.1`, and Java `21` or
newer. It is client-only; no server installation is required.

This is a remapped runtime JAR. Do not use a development JAR or source ZIP as the
installable file.
